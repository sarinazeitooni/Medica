# مدیکا — داشبورد نوبت‌دهی

داشبورد فارسی و راست‌چین برای مدیریت نوبت بیماران (تکلیف استخدامی فرانت‌اند).

## امکانات

- ثبت نوبت جدید با اعتبارسنجی فرم و شماره موبایل ایرانی
- جستجو و فیلتر بر اساس وضعیت
- مرتب‌سازی بر اساس تاریخ و ساعت نوبت
- تغییر وضعیت مجاز: در انتظار → تأیید/لغو، تأیید شده → انجام‌شده/لغو
- آمار لحظه‌ای پس از هر تغییر
- مودال دسترس‌پذیر (فوکوس، Escape، پس‌زمینه)
- حالت‌های خالی، بارگذاری و پیام موفقیت/خطا
- ذخیره در `localStorage`

## اجرا

```bash
npm install
npm run dev
```

## بررسی کیفیت

```bash
npm run lint
npm run typecheck
npm run build
```
